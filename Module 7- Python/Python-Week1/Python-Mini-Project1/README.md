# Dii's Delicacies Receipt

A simple Python mini-project that generates a restaurant bill for a customer order. The program displays the menu items, calculates the subtotal, adds VAT, and shows the final total.

## Project Overview
This project demonstrates how to:
- store menu item names and prices
- calculate totals using variables
- apply VAT to a purchase
- print a formatted receipt to the console

## Features
- Displays a list of food items and prices
- Calculates the subtotal
- Adds 15% VAT
- Prints the final total for the customer

## Learning Objectives
By completing this project, learners can practice:
- creating and using variables in Python
- performing arithmetic calculations
- applying percentage-based VAT calculations
- displaying formatted output in the console
- building a simple real-world billing application

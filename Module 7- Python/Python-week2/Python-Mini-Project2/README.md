# Employee Attendance Tracker

A simple Python mini-project that records employee arrival times and classifies each employee as either on time or late based on a threshold of 8:30 AM.

## Project Overview
This project demonstrates how to:
- store employee data in a dictionary
- loop through records
- compare arrival times against a set cutoff
- calculate an average arrival time

## Features
- Tracks employee clock-in times
- Identifies late employees
- Identifies employees who arrived on time
- Calculates the average arrival time

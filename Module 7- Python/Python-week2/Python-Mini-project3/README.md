# Workout Countdown Timer

A simple Python mini-project that creates a gym workout countdown timer. It displays a 20-second countdown, shows motivational messages before and after the workout, and prints the current date at the start of the session.

## Project Overview
This project is designed to practice basic Python concepts such as:
- functions
- loops
- `time.sleep()`
- date and time handling
- console output formatting

## Features
- Counts down from 20 to 0
- Prints a short start message before the workout begins
- Displays a completion message at the end
- Shows the current date and time

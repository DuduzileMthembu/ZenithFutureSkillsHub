# Vehicle Management System

A simple Python project that demonstrates object-oriented programming concepts such as inheritance and method overriding in a vehicle model.

## Project Overview
This project simulates a basic vehicle management system by creating different types of vehicles, including cars and bikes. Each class inherits from a parent `Vehicle` class and overrides the `Movement()` method to display vehicle-specific behavior.

## Features
- Base class for all vehicles
- Inheritance from the `Vehicle` class
- Method overriding for different movement behavior
- Simple object creation and demonstration of OOP concepts


## Learning Objectives
This project helps practice:
- Classes and objects
- Inheritance
- Polymorphism
- Method overriding
- Python basics in a real-world context

## Notes
This is a beginner-friendly project intended for learning and demonstrating core OOP concepts in Python.

# Student Registry

A simple Python student management system for registering students, adding marks, tracking attendance, and setting assignment deadlines.

## Features
- Register new students
- View all students
- View individual student details
- Add marks
- Record attendance
- Set assignment deadlines
- Save and delete student records


## Files
- `main.py` – program menu and logic
- `student.py` – student classes
- `student_list.py` – student list operations
- `storage.py` – save/load/delete data
- `students.json` – stored student records
